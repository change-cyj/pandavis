# PandaVis 部署指南（获取网站链接）

网站是纯静态文件（无后端、无构建步骤），把本目录原样上传到任意静态托管平台即可获得公开链接。以下三种方式任选其一，**推荐方式一**。

---

## 方式一：GitHub Pages（免费、稳定，推荐）

1. 打开 https://github.com 并登录（没有账号可免费注册）。
2. 右上角 **+** → **New repository**：
   - Repository name 填 `pandavis`（或其他名字）；
   - 选 **Public**；不要勾选任何初始化文件；点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file** 链接。
4. 把本目录下的 **`index.html`、`css`、`js`、`lib`、`assets`、`docs`** 全部拖进上传区域（保持目录结构），点页面底部 **Commit changes**。
5. 进入仓库 **Settings** → 左侧 **Pages**：
   - Source 选 **Deploy from a branch**；
   - Branch 选 **main**，目录选 **/(root)**，点 **Save**。
6. 等 1–2 分钟刷新，页面顶部会给出网站链接，形如：
   `https://<你的用户名>.github.io/pandavis/`
7. 打开链接验证能正常显示（Titanic 数据自动加载），**这就是要提交的网站链接**。

> 提示：如果打开后页面空白，检查上传时 `index.html` 是否在仓库根目录（不能多套一层文件夹）。

---

## 方式二：Netlify Drop（最快，拖文件夹即可）

1. 打开 https://app.netlify.com/drop （需登录，可用 GitHub 账号一键登录）。
2. 把**本目录整个文件夹**拖进页面的虚线区域。
3. 几秒后自动部署完成，得到形如 `https://随机名字.netlify.app` 的链接。
4. 可在 **Site settings → Change site name** 改成好记的名字，如 `pandavis.netlify.app`。

---

## 方式三：Vercel

1. 打开 https://vercel.com 并登录（可用 GitHub 账号登录）。
2. **Add New → Project → Import Third-Party Git Repository** 不适用时，改用：
   安装 Vercel CLI 或直接把方式一的 GitHub 仓库 **Import** 进来，Framework 选 **Other**，直接 **Deploy**。
3. 部署完成后得到 `https://<项目名>.vercel.app` 链接。

---

## 本地预览（自查用）

```bash
# 在本目录下运行（任选其一）
python -m http.server 8000
# 或
npx serve .
```

然后浏览器访问 `http://127.0.0.1:8000`。

> 直接双击 `index.html` 也能运行（所有依赖均已本地化），但部分浏览器对 `file://` 有安全限制，推荐用上面的本地服务器方式预览。

---

## 部署前检查清单

- [ ] 目录结构完整：`index.html`、`css/`、`js/`、`lib/`、`assets/`（`docs/` 可选）
- [ ] 本地打开无 console 报错，Titanic 数据自动加载
- [ ] 部署后访问公开链接，刷新页面验证正常
- [ ] 链接无需登录即可访问（用隐身窗口验证）
