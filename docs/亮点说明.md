# PandaVis 关键亮点说明 · Key Highlights

> PandaVis —— 像使用 pandas 一样探索数据，无需编写代码。
> Explore data like pandas — without writing code.

---

## 一、项目简介 · Overview

**中文**

PandaVis 是一个纯前端、可完全离线运行的可视化数据分析平台。它以 Python pandas 库为蓝本，将 pandas 的核心数据处理能力完整搬入浏览器：用户通过点选式交互完成数据加载、查看、清洗、筛选、转换、聚合与可视化，平台同步生成等价的、可直接运行的 pandas Python 代码。它既是零代码的数据分析工具，也是学习 pandas 的可视化桥梁。

**English**

PandaVis is a pure front-end, fully offline-capable visual data analysis platform. Modeled on the Python pandas library, it brings pandas' core data-processing power into the browser: users load, inspect, clean, filter, transform, aggregate and visualize data through point-and-click interaction, while the platform simultaneously generates equivalent, runnable pandas Python code. It is both a no-code analysis tool and a visual bridge for learning pandas.

---

## 二、关键亮点 · Key Highlights

### 1. 完整而强大的 pandas 功能体系 · A complete pandas feature set

**中文**

自研 JavaScript DataFrame 引擎，在浏览器内实现 **21 种 pandas 操作**，覆盖数据分析全流程：

| 类别 | 功能 |
| --- | --- |
| 查看与统计 | head / tail / sample / info / describe / corr / value_counts |
| 数据清洗 | dropna（any/all + 子集）/ fillna（value/mean/median/mode/ffill/bfill）/ drop_duplicates / astype / rename |
| 筛选与排序 | query（13 种运算符、多条件 AND/OR）/ sort_values（多键升降序）/ select / drop |
| 转换与聚合 | groupby（11 种聚合函数）/ pivot_table / add column（四则运算、字符串、日期提取、条件赋值 np.where、分箱 pd.cut 共 5 种模式）/ merge（inner/left/right/outer 四种连接） |

- 不可变（immutable）变换设计：每次操作产生新 DataFrame，天然支持历史回溯。
- 自动类型推断（数值 / 类别 / 日期 / 布尔），智能排序（数字按数值、日期按时间）。
- 引擎结果经 Python pandas 真实运行结果比对验证（如 iris 数据集的 describe / corr 数值一致）。

**English**

A self-developed JavaScript DataFrame engine implements **21 pandas operations** in the browser, covering the full analysis workflow: inspection (head/tail/sample/info/describe/corr/value_counts), cleaning (dropna, fillna with 6 methods, drop_duplicates, astype, rename), filtering & sorting (query with 13 operators and AND/OR logic, multi-key sort, select/drop), and transformation (groupby with 11 aggregations, pivot_table, add-column in 5 modes including np.where-style conditional assignment and pd.cut-style binning, and merge with 4 join types). Immutable transforms naturally support history replay; automatic type inference and smart sorting are built in. Engine results were cross-validated against real pandas output.

### 2. 操作即代码 —— 同步生成 pandas Python 脚本 · Operations generate real pandas code

**中文**

每一次点击操作，平台都实时生成对应的、**可直接复制运行的 pandas 代码**（含 `import pandas as pd` 头部与变量注释），在「pandas 代码」标签页中按步骤累积成完整脚本，一键复制。这让 PandaVis 同时成为 pandas 的**可视化学习工具**：用户在操作中直观理解 `groupby().agg()`、`pd.cut`、`np.where`、`merge(how=...)` 等 API 的真实写法。

**English**

Every click generates equivalent, **copy-and-run pandas code** (with import header and comments), accumulated as a complete script in the "pandas Code" tab. PandaVis thus doubles as a **visual learning tool for pandas**: users see exactly how `groupby().agg()`, `pd.cut`, `np.where` and `merge(how=...)` are written while they work.

### 3. 专业级数据可视化 · Professional visualization

**中文**

基于 Apache ECharts 构建 **9 种图表**：柱状图、条形图、折线图、面积图、饼图、散点图、直方图、箱线图、热力图（相关系数矩阵 / 双类别透视两种模式）。支持任意列组合、11 种聚合方式、分组多系列、智能坐标轴（类别按数值/时间排序）、数字千分位格式化、一键导出高清 PNG。图表自动适配暗色主题。

**English**

Nine chart types powered by Apache ECharts: bar, horizontal bar, line, area, pie, scatter, histogram, boxplot, and heatmap (correlation-matrix or two-category pivot modes). Supports arbitrary column combinations, 11 aggregations, grouped multi-series, smart axis ordering, number formatting, one-click PNG export, and automatic dark-theme adaptation.

### 4. 自由的数据加载与默认数据集 · Flexible data loading with defaults

**中文**

- 内置 4 个开箱即用的数据集：**Titanic（默认自动加载，891 行含真实缺失值）**、Iris、Tips、Sales；
- 支持 **上传文件**（CSV / TSV / JSON / Excel .xlsx）、**从 URL 加载**、**直接粘贴数据**、以及**拖拽文件到页面任意位置**；
- 已上传的数据集会进入数据集池，可与当前数据做 merge 连接。

**English**

- Four built-in datasets ready to use: **Titanic (auto-loaded by default, 891 rows with real missing values)**, Iris, Tips, Sales;
- Load data by **file upload** (CSV / TSV / JSON / Excel), **URL**, **paste**, or **drag-and-drop anywhere on the page**;
- Uploaded datasets join a dataset pool and can be merged with the current data.

### 5. 完整的工作流：历史、撤销、链式分析 · Full workflow: history, undo, chained analysis

**中文**

每一次变换都记入「操作历史」时间线：支持**撤销 / 重做 / 一键重置**，并可点击任意历史步骤直接回溯到该状态。任何操作结果（筛选、聚合、透视的输出表）都可「**设为当前数据**」继续分析，实现 pandas 式的链式工作流。处理结果可导出为 CSV / JSON。

**English**

Every transform is recorded on a history timeline with **undo / redo / reset**, and clicking any step restores that state instantly. Any operation result (a filtered, aggregated or pivoted table) can be **set as the current dataset** for further analysis — a pandas-style chained workflow. Results export to CSV / JSON.

### 6. 中英双语 & 双主题 · Bilingual & dual-theme

**中文**

全站中英双语一键切换，**两种语言内容完全一致**（约 290 条词条逐一对应，运行时自检缺失词条）；界面文案、操作说明、图表标题、提示信息全部本地化。同时提供亮色 / 暗色两套精心调配的主题，偏好自动记忆。

**English**

One-click Chinese/English switching with **fully consistent content** (~290 entries matched one-to-one, with runtime self-check for missing keys); all UI copy, operation descriptions, chart titles and notifications are localized. Carefully tuned light and dark themes are both available, with the preference remembered automatically.

### 7. 交互简洁、设计美观 · Simple interaction, beautiful design

**中文**

- 三栏式专业布局：左侧操作面板（可搜索、可折叠）、中央多标签工作区（表格 / 结果 / 图表 / 代码 / 历史）、底部实时状态栏（数据集、形状、内存占用、步骤数）；
- 表格支持分页、类型徽标、缺失值高亮、点击表头排序；
- Toast 反馈、模态框、拖拽遮罩、空状态引导一应俱全；
- 现代设计系统：CSS 变量主题、卡片阴影层次、圆角与过渡动画，耐看且专业。

**English**

- A professional three-pane layout: a searchable, collapsible operation sidebar, a tabbed workspace (Table / Output / Chart / Code / History), and a live status bar (dataset, shape, memory, step count);
- The table supports pagination, dtype badges, highlighted missing values, and click-to-sort headers;
- Toast feedback, modals, a drag overlay, and empty-state guidance throughout;
- A modern design system with CSS-variable theming, layered card shadows, rounded corners and smooth transitions.

### 8. 内置「功能导览」自动演示 · Built-in guided tour

**中文**

点击导航栏「功能导览」即可启动 10 步聚光灯导览：平台**自动执行**一条完整的分析流水线（数据概览 → 缺失值填充 → 条件筛选 → 分组聚合 → 生成图表 → 查看代码 → 历史回溯），每步配有双语讲解卡片。它既是新手上手教程，也让功能演示与视频录制变得极其简单。

**English**

Click "Feature Tour" to launch a 10-step spotlight tour that **automatically executes** a complete analysis pipeline (overview → fill missing values → filter → group & aggregate → chart → code → history), with bilingual explanation cards at each step. It serves both as an onboarding tutorial and as an effortless way to demo the product or record a video.

### 9. 零依赖、纯静态、完全离线 · Zero-dependency, fully static, offline-ready

**中文**

所有依赖（ECharts、SheetJS）均已本地化，整个网站是纯静态文件：无需构建、无需后端、无需联网，双击 `index.html` 或任意静态托管即可运行。部署成本为零。

**English**

All dependencies (ECharts, SheetJS) are bundled locally; the whole site is static files: no build step, no backend, no network required. Open `index.html` or drop it onto any static host — deployment costs nothing.

## 四、快速开始 · Quick Start

**中文**

1. 解压源码，进入目录；
2. 直接双击 `index.html`，或运行 `python -m http.server 8000` 后访问 `http://127.0.0.1:8000`；
3. 页面自动加载 Titanic 数据集，点击左侧任意功能开始分析；点击「功能导览」观看自动演示。

**English**

1. Unzip the source code and enter the folder;
2. Double-click `index.html`, or run `python -m http.server 8000` and visit `http://127.0.0.1:8000`;
3. The Titanic dataset loads automatically — click any operation in the sidebar to start, or click "Feature Tour" to watch the auto-demo.
