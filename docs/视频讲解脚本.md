# PandaVis 演示视频脚本（≤ 5 分钟）

> 录制建议：浏览器全屏打开网站（默认已加载 Titanic 数据集），用 OBS / 系统录屏工具录制，分辨率 1080p。
> 旁白用中文朗读即可（如需英文版见每段末尾英文稿）。全程约 4 分 40 秒。
> **省力技巧**：0:50 起可直接点击导航栏「功能导览」，让网站自动执行第 2～6 步的操作，你只需跟着聚光灯讲解；也可以手动操作，按脚本执行。

---

## 分镜与旁白

### 【0:00 – 0:25】开场介绍

**画面**：网站首页，Titanic 数据已加载，891 行表格清晰可见。

**旁白**：
> 大家好，这是我的数据可视化课程作业——PandaVis，一个把 Python pandas 搬进浏览器的可视化数据分析平台。无需编写任何代码，就能完成数据加载、清洗、筛选、聚合到可视化的完整流程，并且每一步都会同步生成真实的 pandas 代码。网站全程中英双语。下面我用默认的 Titanic 数据集来演示。

**EN**: Hi, this is PandaVis — a visual data analysis platform that brings Python pandas into the browser. No code needed: load, clean, filter, aggregate and visualize data by clicking, while every step generates real pandas code. The site is fully bilingual. Let me demo with the built-in Titanic dataset.

---

### 【0:25 – 0:50】亮点一：自由的数据加载

**画面**：鼠标移到左侧「数据」面板，依次悬停：内置数据集下拉框（展示 Titanic / Iris / Tips / Sales 四项）、上传文件按钮、从 URL 加载、粘贴数据；最后拖一个 CSV 文件到页面上展示拖拽遮罩（或仅悬停展示提示）。

**旁白**：
> 数据可以从任何地方来：四个内置数据集开箱即用，也支持上传 CSV、JSON 甚至 Excel 文件、从 URL 加载、直接粘贴数据，或者把文件拖到页面任意位置。当前加载的是 891 行的泰坦尼克数据，注意 Age 列有这些高亮的缺失值，稍后我们来处理它。

**EN**: Data can come from anywhere: four built-in datasets, file upload (CSV, JSON, even Excel), URL loading, pasting, or drag-and-drop anywhere on the page. The Titanic data has 891 rows — note the highlighted missing values in the Age column; we'll fix them later.

---

### 【0:50 – 1:25】亮点二：查看与统计

**画面**：左侧「查看与统计」→ 点击「数据概览 info」的运行按钮 → 切到「结果输出」标签页展示列类型与非空计数表；再运行「描述统计 describe」展示统计表。

**旁白**：
> 首先是 pandas 的看家本领：一键 info，看到每一列的类型推断结果和非空计数——Age 只有 711 个非空值；再来一个 describe，所有数值列的计数、均值、标准差、分位数一目了然，和在 Python 里运行一模一样。

**EN**: First, pandas' signature moves: one click for info() — column types and non-null counts, Age has only 711 non-null values; then describe() — count, mean, std and quantiles for every numeric column, exactly like in Python.

---

### 【1:25 – 2:00】亮点三：数据清洗

**画面**：左侧「数据清洗」→ 缺失值填充卡片：列选 Age、方法选「中位数 median」→ 运行 → toast 弹出「已填充 180 个缺失值」→ 回数据表格展示 Age 列 NaN 已消失。

**旁白**：
> 处理缺失值只要两下点选：选择 Age 列、用中位数填充。180 个缺失值瞬间补全。除了中位数，还有均值、众数、前向、后向填充；删除缺失行、去重、类型转换、重命名，pandas 的清洗功能这里都有。

**EN**: Cleaning takes two clicks: pick the Age column and fill with the median — 180 missing values filled instantly. Mean, mode, forward/backward fill are all here too, plus dropna, deduplication, type conversion and renaming.

---

### 【2:00 – 2:30】亮点四：条件筛选与链式分析

**画面**：左侧「筛选与排序」→ 条件筛选卡片：添加条件 Sex = female，再添加 Pclass = 1，逻辑 AND → 运行 → 表格从 891 行变为约 94 行；点一次「撤销」恢复，再「重做」。

**旁白**：
> 筛选支持十多种运算符和多条件组合。我们筛出「女性、且头等舱」的乘客，891 行立刻变成 94 行。注意顶部的撤销和重做——每一步都是可回溯的。任何结果还可以一键「设为当前数据」，像 pandas 链式调用一样继续分析。

**EN**: Filtering supports a dozen operators and multi-condition logic. Filter for female, first-class passengers — 891 rows become 94. Notice undo and redo up top — every step is reversible. Any result can be set as the current dataset, chained like pandas.

---

### 【2:30 – 3:05】亮点五：分组聚合与透视表

**画面**：「重置数据」→ 左侧「转换与聚合」→ 分组聚合：分组键 Sex、聚合 Survived 取 mean → 运行 → 结果输出显示女性生存率 0.74 vs 男性 0.19；再快速展示透视表卡片（行 Sex、列 Pclass、值 Survived、mean）运行结果。

**旁白**：
> 经典问题来了：泰坦尼克上谁更容易幸存？按性别分组，对生存率取均值——女性 74%，男性只有 19%。换成透视表，性别乘舱位等级交叉分析，也是几次点选的事。十一种聚合函数、四种表连接，都在这个面板里。

**EN**: The classic question: who survived the Titanic? Group by sex, average the survival rate — 74% for women, only 19% for men. A pivot table crossing sex with cabin class takes a few clicks too. Eleven aggregations and four join types live in this panel.

---

### 【3:05 – 3:50】亮点六：专业可视化

**画面**：切到「可视化」标签页。① 柱状图：X=Sex，Y=Survived，聚合=mean，分组=Pclass → 生成（分组柱状图）；② 热力图：类型=热力图、相关系数矩阵 → 生成；③ 直方图：Y=Age → 生成；④ 点「下载 PNG」。

**旁白**：
> 可视化内置九种图表。把刚才的发现画出来：性别为 X 轴、生存率取均值、按舱位分组，一张分组柱状图说明一切——头等舱女性几乎全部幸存。相关系数热力图一眼看清变量间的关系；直方图看年龄分布；散点、箱线、饼图随点随出，还能导出高清 PNG 用在报告里。

**EN**: Nine chart types are built in. Let's plot our finding: sex on X, mean survival rate, grouped by class — one grouped bar chart tells the whole story. A correlation heatmap reveals variable relationships; a histogram shows the age distribution. Scatter, box, pie — all one click away, with PNG export for your reports.

---

### 【3:50 – 4:20】亮点七：操作即代码 + 历史回溯

**画面**：切到「pandas 代码」标签页，展示刚才所有操作生成的完整 Python 脚本，点「复制代码」；再切到「操作历史」，点击中间的某个历史步骤，数据瞬间回溯。

**旁白**：
> 这是我最喜欢的功能：刚才每一步操作，都同步生成了真实可运行的 pandas 代码——fillna、布尔筛选、groupby，一行不少，复制下来就能在 Python 里跑。所以它不只是分析工具，还是学习 pandas 最好的老师。旁边的操作历史记录了每个检查点，点一下就能回到过去。

**EN**: My favorite part: every operation generated real, runnable pandas code — fillna, boolean filtering, groupby, all there, ready to copy into Python. So it's not just an analysis tool, it's the best pandas teacher. And the history panel checkpoints every step — one click travels back in time.
